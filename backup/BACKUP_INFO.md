# Respaldo de la versión original de J-MZ Tness

Este directorio contiene una copia exacta e inalterada de todos los archivos originales de la versión publicada en Netlify (https://gym-progress-mz.netlify.app/):

1. `index.html`: El archivo HTML/CSS/JS original íntegro que servía la aplicación de página única.
2. `original_script.js`: El bloque de código JavaScript extraído para análisis de la lógica de negocio, algoritmos de sobrecarga progresiva y estructuras de datos.
3. `whatsapp image 2026-10-30 at 7.19.51 pm.ico`: El icono y logotipo original del proyecto.
4. `gym-journal_files/css2`: Hoja de estilos original con las fuentes Barlow Condensed e Inter.

**Seguridad de los datos:**
- La estructura de datos de esta versión conserva el formato `gymjournal_v1`.
- La nueva versión incluye un puente de migración automática y manual que detecta e importa cualquier dato previo almacenado en el navegador.
